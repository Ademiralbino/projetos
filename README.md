## 💻 Projetos em Destaque

### 1. 🔐 [Sistema de Autenticação JWT com Flask](https://github.com/Ademiralbino/tela-de-login)
Aplicação full-stack de autenticação de usuários desenvolvida com Python (Flask) no backend e HTML5/CSS3/JavaScript no frontend.
- **Destaques:** Criptografia de senhas com Bcrypt, autenticação via Tokens JWT, persistência com SQLite (SQLAlchemy) e interface com efeito Glassmorphism.
- **Repositório:** [`/tela-de-login`](https://github.com/Ademiralbino/tela-de-login)

### 2. 🔑 Gerador de Senhas Seguras & Análise de Entropia
Ferramenta para geração de credenciais fortes e análise de segurança de senhas.
- **Destaques:** Algoritmos de aleatoriedade segura, cálculo de entropia e estimativa de tempo de quebra por força bruta.

### 3. 🛍️ Plataforma E-Commerce & Landing Pages
Desenvolvimento de interfaces web focadas em experiência do usuário (UX/UI), responsividade e boas práticas de estruturação semântica.
- **Destaques:** Animações CSS, layouts responsivos, manipulação do DOM com JavaScript Vanilla.
